# Classic console expansion

The user requested five more devices at the existing model-delivery standard. The final collection must contain twelve working device entries. The existing seven verified models remain part of the collection.

| Device | Selected version | Distinctive required details |
| --- | --- | --- |
| Atari 2600 | Original woodgrain six-switch VCS / CX2600 | Curved heavy shell, six switches, cartridge reader, joystick/paddle interfaces, major ICs and RF/power sections; classic joystick |
| Famicom | HVC-001 red/white, round-button revision | Eject mechanism, two attached controllers, player-II microphone/volume, cartridge connector, RF and expansion ports, CPU/PPU and RAM |
| Game Boy | DMG-01 grey (1989) | Monochrome LCD, D-pad/AB/select/start, contrast/volume wheels, cartridge well, four AA cells, separate front/main/power/jack boards |
| PlayStation | SCPH-1000 grey launch-family console | Top-loading CD mechanism, two controller and memory-card ports, original digital controller, optical pickup and main/power boards |
| PlayStation 2 | SCPH-10000 Japanese black fat model | Tray-loading DVD, original front interfaces, PC CARD rear layout, DualShock 2, optical drive, power/cooling and major electronics |

## Acceptance contract

Each device receives an independent folder, native editable shell history and detailed scripted geometry, meaningful build stages, complete/exploded assemblies, colored STEP, component inventory, twelve A3 CAD-derived drawing pages in Kami PDF and native FreeCAD sheets, source references, build/open macros and real web meshes. Only validated devices are added to the catalog.

Validate component solids and actual assembly interference, fresh source rebuild, saved native files, one-to-one STEP round trips, drawing dimensions, all PDF pages/fonts, and desktop/mobile browser views. Commit and push reviewable milestones; publish the complete collection and update the README gallery and counts. Public specifications and approximate study dimensions must be distinguished.
