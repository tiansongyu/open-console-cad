# Nintendo 64 references

- [Official hardware information](https://www.nintendo.co.jp/n01/n64/hardware/index.html).

Native geometry, local dimensions and internal layout are original study approximations. Reference photographs are used for research only and are not redistributed. DejaVu Sans is used under its existing repository license.

- [Nintendo original hardware page](https://www.nintendo.co.jp/n01/n64/hardware/index.html): 260 W × 190 D × 73 H mm and original grey NUS-005 controller.
- [NUS-001 firsthand assembly](https://digandrescue.com/hardware/nintendo/nintendo-nintendo64-nus-001/): six case screws, shield stack, ten heatsink fasteners and opposed cartridge shutters.
- [Original NUS-005 controller](https://digandrescue.com/hardware/nintendo/nintendo-nintendo64-nus-005-controller/): geared optical stick mechanism, spring and washer, separate shoulder/Z boards, nine main case screws and two smaller connector-side screws.
- [NUS-008 Jumper Pak](https://digandrescue.com/hardware/nintendo/nintendo-nintendo64-nus-008-terminatorpak/): original terminator module, not the later memory Expansion Pak.
- [iFixit guide 74923](https://www.ifixit.com/Teardown/Nintendo+64+Teardown/74923): physical board, shield and interfaces. The photographed motherboard is NUS-CPU-04 (1996/1997); this is an internal layout reference, not a claim to reproduce the earliest PCB revision. Its generic text calls Multi Out a composite port; the connector is correctly named Nintendo Multi Out here.

- [NUS-004 Controller Pak](https://digandrescue.com/hardware/nintendo/nintendo-nintendo64-nus-004-controllterpak/): battery-backed SRAM, CR2032 marking and two shell fixings. Modeled as an optional study accessory.
- [NUS-006 Game Pak](https://digandrescue.com/hardware/nintendo/nintendo-nintendo64-nus-006-cassette/): bowed upper outline, paired shields, two board/shield fasteners and two case fasteners. The delivered cartridge uses an original blank label.
- [PicoCart64](https://github.com/kbeckmann/PicoCart64): developer-authored cartridge interface reference for the fifty-position bus, not reused as PCB geometry or electrical design.
