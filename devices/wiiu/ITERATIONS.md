# Wii U design iterations

Work in progress: native console and GamePad assemblies. Wiring, accessories and final delivery verification are pending.

| Stage | Source | Work |
| --- | --- | --- |
| 01 | [iter01](scripts/iter01_native_rounded_wup001_enclosure.py) | 按 172 × 268.5 × 46 mm 塑料主体建立原生圆角截面、长向拉伸、空心壳及上下分件，保留独立前面板和外伸脚垫。 |
| 02 | [iter02](scripts/iter02_front_disc_slot_controls_sd_and_dual_usb.py) | 加入吸入式光盘槽、电源与退盘控制、外露红色同步键，以及独立前门内的九接点 SD 卡座与双 USB 接口。 |
| 03 | [iter03](scripts/iter03_rear_hdmi_av_stacked_usb_and_cooling_grille.py) | 补齐背面 HDMI 十九接点、AV 十六接点、感应条与供电口，以及堆叠双 USB、三列排风格栅和两侧通风槽。 |
| 04 | [iter04](scripts/iter04_basic_mainboard_mcm_four_memories_and_emmc.py) | 加入 Basic 主板、CPU/GPU 多芯片载板、四片 DDR3L 与 8 GB eMMC 封装，补齐视频、系统及分区供电器件；内部电路布置明确作为学习近似。 |
| 05 | [iter05](scripts/iter05_underside_radio_modules_and_compatibility_memory.py) | 补齐主板背面的三块独立无线模块、屏蔽罩、微型同轴端口和兼容模式存储器，并调整两枚器件以消除与电容的干涉。 |
| 06 | [iter06](scripts/iter06_mcm_heatsink_axial_fan_and_offset_air_duct.py) | 加入多芯片封装的共用鳍片散热器、后部轴流风扇及原生剖面放样风道，保持散热层与外壳、端口和主板分离。 |
| 07 | [iter07](scripts/iter07_wiiu_slot_drive_pickup_and_pressed_cover.py) | 以共用传送机构原语建立 Wii U 吸入式光驱，重新确定机架尺寸、上盖加强筋和安装点，保留主轴、滚轮、齿轮及导轨光头。 |
| 08 | [iter08](scripts/iter08_shield_layers_support_columns_and_clearances.py) | 加入上下屏蔽板、主板和光驱支柱及机壳螺钉；修正无线接口罩和风道底部的实际装配间隙，避免螺柱超出圆角外形。 |
| 09 | [iter09](scripts/iter09_native_gamepad_curved_grips_and_touch_display.py) | 建立 GamePad 原生曲面前后壳、空心握柄和 6.2 英寸显示层，保留金属背板、LCD 支承、触摸层和黑色细边框的独立组件。 |
| 10 | [iter10](scripts/iter10_gamepad_dual_sticks_buttons_camera_and_nfc.py) | 补齐双摇杆、ABXY、十字键、START/SELECT、HOME 蓝色环、TV 和电源控制，加入前摄像头、红外窗口、NFC 标记及立体声开口。 |
| 11 | [iter11](scripts/iter11_gamepad_shoulders_battery_door_and_edge_ports.py) | 加入 L/R 与 ZL/ZR、可拆电池盖、音量滑块、耳机与充电端口、底部扩展口及充电触点，同时完善主机螺钉和风道的避让。 |
| 12 | [iter12](scripts/iter12_gamepad_boards_nfc_display_support_and_battery.py) | 补齐 GamePad 主板、无线和 NFC 模块、镂空显示支架、原版 1500 mAh 电池、独立按键板、相机、麦克风与立体声扬声器。 |
| 13 | [iter13](scripts/iter13_gamepad_analog_modules_button_domes_and_feedback.py) | 加入双模拟摇杆的回中弹簧、支承和电位器、按键硅胶与推杆、肩键小板及偏心振动机构，保留可独立查看的机械和电子组件。 |
| 14 | [iter14](scripts/iter14_gamepad_fixing_columns_battery_retainer_and_stylus.py) | 补齐 GamePad 外壳和主板固定点、电池盖螺钉与内部承托边框，并加入独立 WUP-015 触控笔学习模型。 |
| 15 | [iter15](scripts/iter15_speaker_select_and_shoulder_clearances.py) | 根据装配求交结果分开右扬声器与 SELECT 推杆，并同步调整扬声器开口；移开肩键小板，使其避让模拟摇杆电位器。 |
| 16 | [iter16](scripts/iter16_case_column_fit_and_native_surface_continuity.py) | 依据全装配求交移动下部螺柱并补齐按键板和支承框的通孔；保留壳体分段曲面以避免自动合并损坏曲线，并执行全部组件严格实体检查。 |
