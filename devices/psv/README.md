# PlayStation Vita · PCH-1000 Wi-Fi OLED

按用户确认的初代 Wi-Fi OLED 版本制作，公开主体尺寸为 182 × 83.5 × 18.6 mm，不包含最大突出部位。

当前已建立 OLED、双摇杆、前后摄像头、后触控板、专用接口、电池、Wi-Fi 主板和左右操作板，以及紧固件、排线和空白专用介质。正在进行装配配合检查；完整图纸与网页预览仍在制作中。
