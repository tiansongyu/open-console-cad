# Sony PSP-1000 初代

正在制作的独立 FreeCAD 学习模型。按用户选定的 PSP-1000 建模，主体公开尺寸为 170 × 74 × 23 mm；后续保留单模拟滑杆、UMD 光驱、Memory Stick、Mini-USB、红外窗口和首代控制布局。

当前已完成 11 轮、346 个组件：外壳、宽屏、初代控制件、接口、后部舱盖、电池、主板与无线模块、UMD 光驱、排线、紧固件和空白可拆介质。正在检查配合并准备正式导出、图纸和网页预览。
