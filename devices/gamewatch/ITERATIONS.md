# Game & Watch DK-52 建模记录

原版橙色双屏掌机的逐轮原生记录。最终铭牌位置和背面展示方向的修订已回写源码。

| 轮次 | 内容 | 组件 |
| --- | --- | ---: |
| 01 | 依据馆藏实测参考包络建立原生橙色分体下壳、空腔、控制面板和两片整幅喷漆金属饰板；局部形状与壁厚近似。 | 9 |
| 02 | 加入独立上壳、显示面框、两侧分段铰链/钢轴与中央前卡扣；原生上盖可绕铰链转动，保留原版侧面凹框。 | 22 |
| 03 | 依据拆解建立两组独立反射片、后偏光层、LCD 玻璃/液晶间隙、固定图形载体、边缘偏光示意、压边和导电胶条。前偏光层按周边框表达，便于观察结构；无背光或触控。 | 108 |
| 04 | 以原机照片为参考重绘两屏红色钢架、梯子、上屏蓝色建筑和吊钩；图形为独立矢量实体的结构示意，不是精确游戏图像或 ROM。 | 149 |
| 05 | 加入原版十字键、圆形 JUMP、竖排 GAME A/B/TIME、凹入金属 ALARM/ACL 触点以及独立导电胶；开孔、按钮与内部碳接点分别建模。 | 182 |
| 06 | 完成外侧横纹金属标题板、开盖后 DONKEY KONG / Nintendo 铭牌、GAME & WATCH 标识与原版按键文字；背面标注两枚 LR44/SR44 和 DC3V，不复制馆藏序列号。 | 219 |
| 07 | 按原机照片建立带电池缺口的酚醛主板、绿色控制面、菱形 SM510 封装和独立引脚/碳接点。器件身份参照 MAME 原始逆向源码，局部封装与布线为非功能近似。 | 340 |
| 08 | 补入背面圆柱时钟晶体、两枚电容、陶瓷/轴向分立件和独立引线焊点；布置参照拆解照片，电气参数和精确电路不作复刻。 | 370 |
| 09 | 加入两枚 LR44/SR44 学习电池、独立金属杯/端盖/密封圈、圆形电池仓和接点，并据存留原机照片建立滑动电池盖及方向箭头。 | 394 |
| 10 | 建立后壳压电音片的黄铜基片、陶瓷层、电极和两根独立红色导线；原机为压电发声结构，不混用现代扬声器或振动马达。 | 402 |
| 11 | 建立原版上屏冲压金属压板、窗口、压筋及五枚独立小螺钉/螺柱，并补入两屏玻璃定位边；压板不是一块替代屏幕的封闭金属片。 | 423 |
| 12 | 补齐五枚下壳长螺钉、四枚上盖外螺钉、五枚主板小螺钉，加上前轮五枚压板螺钉共十九枚；保留各自孔、沉座和独立螺柱。 | 456 |
| 13 | 加入中央外露白色印刷排线、四十条黑色导体和上下独立引出片；排线绕开固定柱，卷曲桥段用于开合间隙示意，不作为柔性寿命或电路认证。 | 579 |
| 14 | 补入少量独立黑色液晶人物/桶/时钟段和面壳细脊，明确是按原机视觉重构的非功能示意，保留双屏固定游戏的外观。 | 587 |
| 15 | 补齐下屏绝缘支承框与上下屏横向定位止口；保留原版电池供电、反射式双 LCD 和机械开合结构，进入独立重建及多姿态完整核验。 | 592 |
