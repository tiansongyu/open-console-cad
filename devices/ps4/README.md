# Sony PlayStation 4 · CUH-1000A

新增批次第 1 款，已完成 24 轮、899 个组件，建模仍在进行中。选择 2013 年初代黑色机身和 CUH-ZCT1 DualShock 4。

[来源与建模边界](references/SOURCES.md) · [参数](profile.json) · [逐轮记录](ITERATIONS.md)

采用约 275 × 305 × 53 mm 主体包络，保留斜面、亮面硬盘盖、磨砂顶壳和分层接缝。所有局部尺寸均为照片指导的近似；当前工程尚未通过完整交付验收，不加入正式网页目录。

壳体、主要接口、存储、主板、散热、电源、光驱和两条排线已进入分轮检查。电机线束、主板供电和硬盘 SATA 主板插座已补齐。机壳固定件、控制器主板、输入机构、线束、接口与四组固定件已生成。后续继续主机末端电气与装载细节、原配附件，再执行整套重建、干涉、STEP、图纸与网页验证。
